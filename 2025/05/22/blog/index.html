将 Hexo 生成的静态网站部署到服务器并绑定域名，可以按照以下步骤操作：

一、准备工作

  1. 拥有服务器
    • 确保你有一台云服务器（如阿里云、腾讯云、AWS 等），并获取服务器的 IP 地址。
    • 确保服务器开放了 80（HTTP） 和 443（HTTPS） 端口（可通过安全组或防火墙配置）。
  2. 域名已购买
    • 确保域名已购买（如从阿里云、GoDaddy 等注册商购买），并可以管理其 DNS 设置。

五、配置域名 DNS 解析

  1. 登录域名管理后台（如阿里云、Cloudflare 等）。
  2. 添加 A 记录：
    • 主机记录：@ 或 www（如 www.your-domain.com）
    • 记录类型：A
    • 记录值：服务器的 IP 地址

六、启用 HTTPS（可选但推荐）

按提示操作后，Nginx 会自动配置 HTTPS。

七、验证访问

  1. 浏览器访问 http://your-domain.com 或 https://your-domain.com。
  2. 若显示 Hexo 网站，则部署成功！

常见问题

  • 403 Forbidden：检查文件权限（chmod -R 755 /path/to/webroot）或 Nginx 的 root 路径。
  • Nginx 启动失败：运行 sudo nginx -t 检查配置文件语法。
  • DNS 未生效：等待 10 分钟~24 小时，或使用 dig your-domain.com 检查解析。

完成以上步骤后，你的 Hexo 网站已部署到服务器并绑定域名！后续更新只需重新生成静态文件并上传即可。
