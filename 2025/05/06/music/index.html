标签页
标签页文件名不一定是 tags, 例子中的 tags 只是一个示例
记得添加 type: “tags”

参数 解释
type 【必须】页面类型，必须为 tags
orderby 【可选】排序方式：
random - 随机排序 / name - 标签名字排序 / length - 标签数量排序
order 【可选】排序次序：1（升序），-1（降序）
